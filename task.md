# BRACE_RCE Roadmap & TODO List

## Phase 1: Core Stability & Matchmaking Polish
- **Disconnect Handling:** Handle edge cases where an opponent leaves or disconnects during an active battle (auto-win for the remaining player).
- **Cancel Matchmaking:** Add an option/button for users to cancel their matchmaking search while in the queue.
- **Match Acceptance Step:** Require both users to click "Accept" when a match is found *before* the problem is revealed and the match starts.
- **Matchmaking Filters:** Add options to filter by difficulty or topic/tags before joining the matchmaking queue.
- **Battle Timer:** Add a countdown timer to the Battle Arena so matches are time-boxed.

## Phase 2: Custom Games & Friends
- **Friends System:** Allow users to add/remove friends.
- **Custom Rooms:** Allow users to generate a room code to directly invite and challenge specific friends.
- **Playlist Challenges:** Challenge friends to a sequence of problems (a playlist) rather than a single question.

## Phase 3: Communication & Collaboration
- **In-Battle Chat:** A small chat thread inside the Battle Arena for players to talk or share code snippets.
- **Global Public Chat:** A global lobby chat through which all users can communicate.
- **In-Battle Notes:** A scratchpad/notes section in the arena for users to jot down thoughts during a match.

## Phase 4: UI/UX & Polish
- **Mobile Optimization:** Redesign and optimize the coding environment and layout to be mobile-friendly.
